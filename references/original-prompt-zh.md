# 原始提示词

以下正文由用户提供；「主体描述」为每次创作时替换的内容槽位。

为「主体描述」创作一幅细腻的手绘肖像，融合当代写实油画与彩色铅笔质感。人物面部刻画充分，保留自然的皮肤纹理、细微的不对称和真实表情；眼神鲜活，嘴角放松，带着若有若无的笑意。
采用竖幅半身近景，视线与人物平齐，构图亲近自然。柔和的侧窗光照亮面庞，明暗过渡温润。整体使用低饱和的暖灰、米褐、深棕与炭黑色，肤色有细腻的冷暖变化。
让笔触清晰可见：头发以松动、富有方向感的线条描绘，衣物以厚实而概括的色块表现，背景保留画布纹理、干刷痕迹与轻微刮擦感。面部尤其是眼睛保持精细，向头发边缘、肩膀和背景逐渐转为自由、松散的笔触，部分轮廓自然融入底色。
画面安静、温暖，有面对面交谈的亲近感。避免磨皮、美颜、塑料皮肤、过度锐化、商业写真感、动漫大眼和光滑的数码渐变。无文字，无水印。
