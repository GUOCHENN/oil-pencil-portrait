# 真实照片转绘模板

将附带的真实照片转绘为一幅细腻的手绘作品，融合当代写实油画与彩色铅笔质感。原照是唯一内容来源。保留原有的人物数量、身份、年龄外观、面部特征、发型、配饰、服装、姿态、视线与真实表情，仅转换绘画媒介；不要强制加笑容或重新设计人物。

保留照片中最有意义的动作与空间关系：【描述照片里可见的动作、关系与关键物件】。人物面部尤其是眼睛充分刻画，保留自然皮肤纹理、细微的不对称、细腻冷暖变化。叙事关键的双手和物件同样需要准确清楚。

构图沿用原照视角和画幅，完整保留重要动作。只有适合单人近景且不会损失内容时，采用竖幅半身构图。不要把互动场景裁成互不相关的单人头像。

使用柔和侧向光，保留原照光向，明暗过渡温润。以低饱和暖灰、米褐、深棕与炭黑为主，保留少量来自原照的必要色彩，肤色有细腻的冷暖变化。

笔触清晰可见：头发以松动、富有方向感的线条描绘，衣物以厚实而概括的色块表现；背景保留原环境的主要空间线索，同时以画布纹理、干刷痕迹与轻微刮擦感处理。面部、眼睛与关键双手精细，向次要衣物边缘和背景逐渐转为自由笔触，部分轮廓自然融入底色。

画面安静、温暖、亲近。情绪来自原有动作，不新增人物、道具或虚构经历。避免磨皮、美颜、塑料皮肤、过度锐化、商业写真感、动漫大眼、光滑数码渐变、过度几何化、畸形双手。无新增文字，无签名，无水印。每张照片输出一幅独立完整画作，不拼图，不上下对照。
