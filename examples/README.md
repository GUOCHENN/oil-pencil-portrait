# 三组真实照片转绘测试

## 观察

共读与握手两组沿用横幅 3:2；陶工沿用竖幅 2:3。未强制裁为竖幅头像，目的是完整保留动作、双手与场景关系。

三张均保留了原有的人数、发型、服装大体特征及主要行为。共读图保留指向书页的手、书本和画笔；握手图保留对视与手部接触；陶工图保留低头姿态、塑形双手及陶轮。均有可见笔触，面部与关键双手较精细，背景处理较松。

结果整体比原照更暖、更明亮，个别轮廓、皮肤细节和环境小物有所重绘。它们是生成式绘画转译，并非像素级复刻。手部、配饰和脸部相似度在新照片上仍需逐张检查；不能把本次样例视为所有输入都能完全保真的保证。

本组测试验证的是“保留真实场景的关系与动作，同时应用油画和彩铅笔触”。画意标题是对可见行为的创作性概括，不是对人物真实生平或亲属关系的认定。
